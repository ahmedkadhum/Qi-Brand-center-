32 — Primary typeface · Latin

FF Mark Pro.

Use the lighter versions of FF Mark Pro for primary body copy. For more punch against coloured backgrounds, use FF Mark Pro Book. Use Bright Teal to highlight important words — a way to add freshness to copy.

34 — Latin hierarchy

Override the digital divide.

Flush left ragged right

Aim to use the traditional alignment (flush left, ragged right) for most applications.

Centered type

Centred type is useful when making a bold statement — but reserve it for those moments.

Baseline grid · 16pt

A 16pt baseline grid allows for a larger line height when setting type. This gives all type more space to breathe — necessary even when using heavier weights.

Highlighting words

Use Bright Teal to highlight key words. Never highlight the full stop at the end of a sentence — punctuation must remain in the main body copy colour.

35 — Primary typeface · Arabic

29LT Bukra.

Bukra was created alongside Arabic, resulting in synergy between the two scripts. Both Arabic and Latin display large open counters and possess many similarities. Bukra reflects a modern view of the world.

ويتلذ بالآلام.

لكن لا بد أن أوضح لك أن كل هذه الأفكار. شيء نقطة السبب وقوعها.

37 — Arabic hierarchy

Mirror of the Latin hierarchy.

Flush right ragged left

Aim to use the traditional Arabic alignment (flush right, ragged left) for most applications.

Centered type

Centred type is useful when making a bold statement.

Baseline grid · 16pt

A 16pt baseline grid allows for a larger line height — same rule as Latin.

Highlight color

Yellow is also used to highlight copy in Arabic — depending on the colour of the layout. Never highlight the full stop.

38 — Digital safe fonts

Tahoma — Mac and PC.

When FF Mark Pro and 29LT Bukra are not available — for example in email signatures or on systems without licensed fonts — fall back to Tahoma. It pairs well with both Latin and Arabic and ships on every Mac and PC.
