Section 07 — Our Grids & Layouts

Hierarchical messaging.

All Qi layouts sit on an A4 ISO modular grid — 10×14 vertical, 14×10 horizontal. The grid resizes for any A-series paper. Three zones organise every page: 3D icon space, content space, and the Qi icon + URL space. The brand splits 80/20 — Specific (icon-led) and General (image-led).

55 — Vertical grid

10 × 14 modules.

The grid is based on an ISO standard A4 format composed of 10 columns × 14 rows. The grid fits the standard ISO 216 A series — it can be resized to fit all A-series papers (A0 up, A5 down). Always respect margins so all elements breathe and stand clear from the edge — except photography and the graphic device, which can bleed.

56 — Horizontal grid

14 × 10 modules.

The same A4 grid, rotated. Composed of 14 columns × 10 rows. Two different margins are provided for added flexibility — when possible, use the larger margin for added space.

57 — Grids for additional formats

Scale, then add cells.

  1. Take the standard A4 grid — 14×10 or 10×14 depending on orientation.
  2. Scale it to the desired size. If that fits, you're done.
  3. If it doesn't, add cells by duplicating horizontally or vertically. Try to keep the cells as perfect squares.
  4. Finally, scale only in the orientation needed to fit the final format. Aim to add cells that minimise scaling.

Once scaled, you usually only need to add cells in one orientation, not both.

58 — Layout types

Three layouts. Each with a job.

Layout 1

Standard with 3D icon

The standard layout to use in most occasions. Use when more type is needed and when applying the 3D icon graphic.

Layout 2

Graphic device on light photo

Layouts using the graphic device are for short messaging only. When displaying copy against a light photographic background, use the device to hold the copy.

Layout 3

Copy on image background

For shorter messaging and more impact, place copy directly on the image background — without the device. Ensure enough contrast between copy and photography.

Layouts 1 + 2 cover ~80% of communications; Layout 3 the remaining ~20%.

59 — Layout hierarchy

Specific ↔ General.

Our messaging system is organised in a hierarchical form. Specific messaging makes use of all iconography to talk about specific aspects of Qi. General messaging makes more use of photography to deliver a broader message.

60 — Which layout to use

80% Specific · 20% General.

Specific · 80%

Clear and simple.

Specific copy that uses iconography in the 3D environment state. Use these layouts 80% of the time.

General · 20%

Aspirational.

More aspirational, drawing customers in and communicating what Qi is about at a broader level. Use these layouts 20% of the time.

63 · 67 — Standard layouts

Three zones, top to bottom.

For all A-size formats, every standard layout splits into three vertical zones — separated by single-cell margins for breathing room.

1 · 3D icon space

Top 5 cells

The icon occupies the top five cells, leaving one cell as a border between icon and content.

2 · Content space

Middle

Content takes the space between the 3D icon space and the Qi icon space, leaving one cell above and one below.

3 · Qi icon + URL

Bottom 3 cells

The Qi icon / brandmark and URL occupy the bottom three cells, always with one cell of clearspace.

64 · 68 — Layouts with imagery

Photo + copy + Qi mark.

When using imagery without the 3D icon, photography fills the upper content space. Copy can be placed anywhere within the grid, leaving one cell between copy and the Qi icon / URL space. Choose imagery that allows sufficient contrast for both the brandmark and the copy.

65–66 · 69–70 — With graphic device

Imagery bleeds. Device holds the copy.

When using the graphic device, imagery fills the entire format — bleeding off the page. The Qi icon is centred to the circular portion of the device. Content is centred horizontally inside the device, with one cell between copy and the Qi icon. The URL must sit at least half a cell within the graphic device. The device is extendable — extend it to accommodate longer copy or to better balance the image.
