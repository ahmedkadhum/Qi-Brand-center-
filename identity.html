Section 01 — Brand Identity

Brandmark.

The Qi brandmark consists of two main elements — the wordmark and the Qi icon. The wordmark is simple, bold and geometric: a modern approach that brings Qi into the modern world. The icon's ring symbolises Qi's protection; the lowercase i inside represents the person being protected by Qi's services.

04 — Brandmark elements

Two parts. One signal.

The Qi brandmark is built from a wordmark and an icon. Both are clean, bold, geometric — an accessible design that people can relate to.

05 — Qi icon breakdown

A symbol, decoded.

Figure 1

The ring is protection.

The ring surrounds the letter i to symbolise Qi's protection. Continuous, unbroken at the top — a closed loop the customer sits inside.

Figure 2

The i is a person.

The lowercase i represents a person being protected by Qi's services. The diagonal stem extends through the ring — the person is connected to the world but covered by the system.

06–07 — Clearspace

x = the thickness of the ring.

Clearspace is always derived from the Qi icon's own ring. The minimum is two times the thickness of the letter "Q" (shown as x). When possible, give it more.

Brandmark clearspace
Minimum 2x · Maximum: more
The rule
  1. Measure x — the stroke width of the icon's ring.
  2. Minimum clearspace — keep 2x on every side, around the wordmark or the standalone icon.
  3. Maximum clearspace — there is no maximum. When possible, add more breathing room.

The same rule applies whether you place the icon on a flyer, a website header, a card, or a building facade.

08 — Minimum size

How small can it go.

Below these sizes the icon and wordmark stop being legible. They are absolute floors — never go smaller.

Digital

145px brandmark · 58px icon

The minimum size of the full Qi brandmark in any digital format is 145px. The standalone Qi icon goes down to 58px.

Print

15mm brandmark · 10mm icon

The minimum printed size of the brandmark is 15mm. The standalone icon prints down to 10mm.

09 — Signage clearspace

In signage, the ring opens up.

For signage purposes, the Qi icon and brandmark may be placed inside a circle or a modified elliptical shape — the same "extended cylinder" used as the brand graphic device. The clearspace inside that container is 2x the icon's ring thickness. For storefronts the device is extended to fit the full width of the fascia.

Normal signage

Place inside circle. Clearspace = 2x.

Storefront

Extend the device to fit the storefront width.

Illuminated sign

White icon inside an illuminated circle.

16–17 — Qi cards

Standard, Credit, Additional.

The card range splits into three families. Standard cards use the primary palette directly. Credit cards lean on the 3D Qi icon rendered in metallic finishes — silver, gold, platinum — to sell exclusivity. Additional cards extend the system into bespoke colour pairings (Select, Pure, etc.).

Standard

Yellow · Gray · Teal

Direct use of the primary colour palette. Debit, Student, Family.

Credit

Silver · Gold · Platinum

3D Qi icon rendered in metallic inks to feel premium. Printing layers use metallic inks plus satin laminate for a smooth finish.

Additional

Select · Pure · …

Bespoke colour pairings using the 3D Qi icon to create new offerings.

Standard finish

Primary colours printed with satin laminate for a smooth, premium feel.

Premium finish

Layers printed with metallic inks, finished with satin laminate.

Card structure is fixed except for the contact-less mark, which moves on Mastercard variants — Mastercard takes the bottom-right corner, the contact-less mark moves to make room.

18 — Using the Qi name in text

"Qi" — uppercase Q, lowercase i.

In running text, always use uppercase Q and lowercase i. The Qi name appears in the same font as the surrounding text — never replace the word with the icon. The same rule applies to "Qi Card" (uppercase Q, uppercase C). The only exception is URLs, which don't allow spaces — there it's fine to write the name continuously.

Do
  • Qi
  • Qi Card
  • Qi.com
  • Qicard.com (URL exception)
  • Get the Qi Card that is right for your needs.
Don't
  • QI · qi
  • Qi card · QiCard · qicard
  • Substituting the icon for the word "Qi" in a sentence
  • Recolouring the word "Qi" mid-sentence
19–20 — Co-branding

Dominant brand on the right or top.

When co-branding, the dominant brand always sits on the right or on top; the subordinate / partner sits on the left or bottom. Both the Qi brandmark and the standalone Qi icon follow this rule.

  • The default is the yellow version of the Qi brandmark / icon.
  • Both brandmarks should be the same visual size.
  • When locked up, separate them by a distance of one X (the inner-circle height of the Qi icon).
  • Never use a vertical pipeline divider or any visual divider between the brandmarks.
21 — Multiple co-branding

Use a modular grid.

When several entities are displayed together, lay them out on a modular grid. The brandmark size of additional partners is calculated by taking the height of the inner circle of the Qi icon (X). The minimum spacing between brandmarks is one square. When a variety of entities is displayed, stack additional rows leaving one square between lines; use one row of squares as gutter between groups.

22 — Qi icon placement

Bottom right, by default.

All general communications — adverts, posters, flyers — display the Qi icon and brandmark in the bottom right corner. This is the preferred position. The exception is when the icon is placed inside the graphic device: there the icon is centred to the device.

23 — Brandmark and icon sizing

A percentage of the format height.

The size of the Qi brandmark / icon is expressed as a percentage of the format's height. Use these caps as the upper limit; smaller is fine.

Small horizontal formats

Up to 15% max

Standard horizontal layouts — flyers, brochures, social posts.

Small vertical formats

Up to 10% max

Standard vertical layouts — posters, A4 spreads.

Extreme horizontal

Up to 20–25% max

Extreme billboards or large hoardings.

Extreme vertical

Up to 12% max

Extreme vertical formats — outdoor adverts.

24 — Qi and URL placement

URL on the opposite side.

The URL is centred horizontally to the height of the Qi icon. It sits on the opposite side of the layout, touching the margin. The URL type height is achieved by dividing the Qi icon in half, then dividing that half again — so URL height ≈ ¼ of the Qi icon's height. The lockup standard for general communications places Qicard.com bottom-left and the Qi icon bottom-right.

25–26 — Things to avoid

Eight rules we never break.

A short list of misuses that ruin the brandmark. The only exception is rule 5: shadows are allowed inside the 3D Qi icon used for credit cards, but never on the flat brandmark.

01 · Rotate

Never rotate the Qi brandmark in any direction or angle.

02 · Recreate

Never recreate parts of the Qi brandmark — always use the artwork files.

03 · Crop

Cropping never displays the brandmark properly. Always show it in its entirety.

04 · Mask

Never use the Qi brandmark as a mask to represent an idea.

05 · Add shadows

Shadows deter from the brand's simplicity. Avoid effects at all times — except inside the 3D Qi icon used for credit cards.

06 · Modify color

Never recolour the Qi brandmarks. Use the supplied artwork files for consistency.

07 · Scale unevenly

Always scale the Qi brandmark proportionally. Failing to do so creates unwanted warping.

08 · Insufficient contrast

Use the right colour variant for maximum contrast against the background — visibility is non-negotiable.
